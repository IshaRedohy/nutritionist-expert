# A nutrition expert chef AI agent

### Phase-1 (Initiate the prompt and model)

This is a local AI agent powered by [llama3.1](https://ollama.com/library/llama3.1) model and [langchain](https://docs.langchain.com/oss/python/integrations/chat/ollama). You input a list of food ingredients and the model replies with a table of its nutritional values. This is the phase 1 of the project. In next phase I will add documents containing nutrional facts of over thousands of ingredients so that the model can reply more precisely and fastly.
